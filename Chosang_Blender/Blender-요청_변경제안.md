# Blender-요청.md 변경 제안 (블렌더 작업 결과에서 나온 것)

1. **입 중심 y ≈ 0.380** (계약 0.357). 눈 간격 0.064 균일 스케일이면 ARKit 비율상 입은 0.380, 턱끝 0.334. 검증기는 고정값 대신 template.json 의 값을 기준으로.
2. **`Neck` 이름 충돌**: 영역 그룹 `Neck` 과 Neck 뼈 디폼 그룹이 같은 이름. 하나로 합쳐 값 = Neck 뼈 스킨 가중치. 목 영역 집합은 '가중치 > 0' 으로.
3. **눈알 중심 깊이**: 소반 −0.0742(블렌더 y) 대비 2.03 mm 뒤. 구멍 정점이 눈알 안으로 들어가지 않게 하려면 필요.
4. **패치 해시**: OBJ 면은 사각형 1152개(삼각형 아님). ARKit 런타임은 삼각형 2304개라 '삼각형 해시' 는 대각선 선택에 따라 달라짐 → 사각형 해시(OBJ 순서) 또는 정렬 불변 해시로 정의.
5. **수염**: '셰이프키 없음 + Head 스킨' 으로는 jawOpen 때 턱에서 떨어짐. Beard_* 에 정점 속성 `chosang_bust_index`(원본 Bust 정점)를 넣었으니 앱이 Bust 변형을 복사해 따라가게 하는 방식을 계약에 추가.
6. **어깨 옷**: Root 100% 대신 Bust 의 Root/Neck 가중치를 복사(목둘레가 목을 따라가야 함).
7. **클립**: 슬롯 액션(4.4+) 기준. 4.1 지원 범위를 유지하려면 스크립트가 분리 처리.
8. **Mouth_Inner**: jaw*·tongueOut 셰이프키 5개(Bust 값과 같은 이름으로 구동).
9. **프리비즈**: 라이브러리 없이 맨 흉상으로 렌더(비교 화면도 같은 조건 권장). 조준점 (0, 0.41, 0.09), 카메라 (0, 0.41, 1.29), 수평 FOV 39.60°.
